# ghyab — سجل غياب منسوبي المدرسة

تطبيق ويب لحصر غياب وتأخر منسوبي المدرسة، وإصدار وطباعة "مساءلة غياب" و"قرار حسم غياب" بنموذج وزارة التعليم.

- `index.html` — التطبيق كاملاً في ملف واحد (يعمل من GitHub Pages أو بفتحه مباشرة).
- البيانات تُحفظ في متصفح كل جهاز (localStorage) في هذه النسخة. لمشاركة البيانات بين الأجهزة يلزم ربطه بقاعدة بيانات سحابية (Firebase) — انظر قسم "المزامنة السحابية".

## التشغيل عبر GitHub Pages
Settings ← Pages ← Source: **Deploy from a branch** ← Branch: **main / (root)** ← Save.
الرابط: `https://<اسم-المستخدم>.github.io/ghyab/`

## أول استخدام
1. أنشئ حساب مدير النظام عند أول فتح.
2. من **الإعدادات ← استعادة من نسخة** ارفع ملف النسخة الاحتياطية (JSON) لاستعادة قائمة المنسوبين والبيانات.

## المزامنة السحابية
النسخة الحالية محلية. لجعل الرابط يعمل لأي شخص مع حفظ مشترك، تُربط بـ Firebase Realtime Database (مجاني). راجع المحادثة الأصلية لخطوات الربط.
